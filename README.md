# CycleCync

> **Simple Data. Big Impact.**

CycleCync is a personal health application designed to help people better understand their menstrual cycles through simple daily observations, personalized analytics, and AI-powered insights.

Rather than focusing primarily on fertility or pregnancy tracking, CycleCync encourages users to discover their own unique patterns by recording a few meaningful data points each day.

The goal is simple:

> **Replace confusion with understanding.**

---

## Why CycleCync?

Many cycle tracking applications focus on predicting ovulation or fertility.

CycleCync takes a different approach.

By collecting only a handful of daily observations, users gradually build a personalized dataset that helps answer questions such as:

- Why do I usually feel tired this week?
- When do I typically have the most energy?
- Are my cycles becoming more regular?
- What patterns have appeared over the last few months?

Instead of generic advice, CycleCync learns from each user's own history.

---

## Features (MVP)

### User Accounts

- Secure account creation
- Login authentication
- Personal data storage

### Daily Check-In

Users spend less than five minutes recording:

- Basal Body Temperature (BBT)
- Mood
- Energy Level
- Sleep Quality

### Dashboard

Visualize personal trends through:

- Temperature charts
- Mood trends
- Energy trends
- Cycle calendar

### Personalized Insights

After multiple cycles are recorded, CycleCync begins identifying patterns unique to each user.

Examples include:

- Typical high-energy days
- Average cycle length
- Mood changes throughout the cycle
- Temperature trends

### AI Assistant

Ask questions in natural language such as:

- "Why am I feeling tired today?"
- "When do I usually have the most energy?"
- "How does this cycle compare to previous ones?"

Responses are generated using the user's own historical data.

## Project Philosophy

CycleCync is built around a few simple ideas:

- Small data can reveal meaningful insights.
- Consistency is more valuable than perfection.
- Every person's cycle is unique.
- Understanding reduces confusion and fear.
- AI should explain—not replace—personal understanding.
